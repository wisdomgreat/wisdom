## ⚡ Tech Stack & Architecture

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 + Custom Cyber-Executive Doppelrand Components
- **Icons**: Lucide React
- **Typography**: Plus Jakarta Sans (Headings/Body) + JetBrains Mono (Code/Telemetry/CLI)
- **Deployment**: Zero-configuration build, optimized for Cloudflare Pages / Vercel / Netlify / Self-hosted Docker

1. **Interactive Executive Shell (CLI)**:
   - Toggle with `Ctrl+K` or `Cmd+K` anywhere on the page
   - Command history navigation with `↑` and `↓` arrow keys
   - Supported commands: `whoami`, `skills`, `projects`, `homelab`, `garden`, `ping`, `contact`, `resume`, `clear`, `help`
2. **Interactive Hybrid Homelab Topology**:
   - Inspect Proxmox VE bare-metal clusters, Windows Server SCCM, Ubuntu Docker automation hosts, and Cloudflare Zero Trust encrypted tunnels
   - Live simulated ICMP ping testing (`ping node`) with zero inbound exposed ports
3. **10+ Production Platforms & Engineering Builds**:
   - Filterable by Category (`Platforms & SaaS`, `AI & Automation`, `FinTech & LegalTech`, `Media & Web Apps`)
   - Instant search across tech stacks, titles, and descriptions
   - Deep-dive "Inspect Architecture" modal
4. **Interactive Consultation Scope Estimator**:
   - Real-time deliverable scoping and effort hour estimations
   - Instant copyable architecture brief
   - Direct dispatch form with email transmission fallback
5. **Printable Capability Statement & Resume**:
   - Clean typographic layout optimized for `@media print` and PDF export
6. **Beyond the Terminal**:
   - Bradford backyard agronomy & Kratky passive hydroponics, Pocket FM serialized storytelling, 4K broadcast field production (Panasonic HC-X1500), and mechanical automotive diagnostics.
7. **Adaptive Theme Engine**:
   - Dark/Light mode toggle with persistence via `localStorage` and `html.dark` synchronization.
